# Sana & Sahil Wedding Invitation Website

Open `index.html` in a browser to preview the mobile-friendly invitation.

## Included files
- `index.html` — invitation website
- `assets/heart-ring.png` — ring image used on the invitation
- `assets/wedding-melody.wav` — original instrumental loop used by the music button

Tap the music button to play or pause the music. The browser starts audio only after the guest taps the button.

The site can be published by uploading the contents of this folder to a static website host. The homepage is `index.html`.
